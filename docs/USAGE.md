# MemoDeck · 使用说明

面向使用者。开发者请看 [架构设计](./ARCHITECTURE.md)，题库格式看 [JSON 规范](./EXAM_JSON_SPEC.md)。

## 一、最快上手

**双击 `index.html`**。就这样，不需要装任何东西，不需要联网。

页面会加载内置的示例题库（初中历史 13 题），你可以直接开始体验所有功能。

## 二、导入自己的题库

点右上角 **⚙️ 数据管理** 展开面板，五种方式任选：

| 方式 | 操作 | 适用场景 |
|---|---|---|
| **拖拽文件** | 把 `.json` 文件拖进虚线框 | 本机已有题库文件 |
| **点击选择文件** | 点虚线框里的「点击选择文件」 | 同上，更明确的入口 |
| **粘贴 JSON** | 展开「📋 或粘贴 JSON 文本录入」，粘贴后点「📥 应用粘贴的 JSON」 | 从 AI 对话、聊天窗口里复制来的 JSON |
| **远程链接** | 填 URL 后点「🌐 远程导入」 | 题库托管在网上，希望随时刷新 |
| **放 `data.json`** | 把题库命名为 `data.json` 放在应用同目录 | 部署后希望打开即用（需 http/https） |

导入成功后会写入浏览器 localStorage，**下次打开自动恢复**，不用重复导入。

### 顺手的几个按钮

- **🔄 刷新** —— 按当前数据源重新拉取
- **⬇️ 下载 JSON** —— 把当前题库导出成文件
- **📋 复制 JSON** —— 复制到剪贴板
- **📘 JSON 规则** —— 下载格式说明，方便丢给 AI
- **🧹 清空缓存并重载** —— 清掉缓存回到内置题库

> ⚠️ 远程链接导入依赖目标服务器允许跨域（CORS）。如果对方不允许，改用「粘贴 JSON」或「选择文件」。

## 三、四个模式

### 🕹️ 记忆闯关 —— 主力背题模式

基于 **Leitner 间隔重复**算法，不是简单刷完一遍就完事：

1. 先看题干，心里想答案
2. 点 **👀 想好了，看答案**
3. 自评：**😎 记住了** / **😥 没记住**

算法的调度规则：

| 你的选择 | 系统行为 |
|---|---|
| 记住了 | 当场判定「掌握」，**移出队列**，进度条向前推进 |
| 没记住 | 该题加入错题本（见下），卡片埋到 **5~7 张**之后，保证中间至少隔四五道别的题才可能再次刷到 |

顶部进度条显示剩余卡片数与已掌握数。全部掌握后显示通关页，可「🔄 再刷一遍」重新开始。

按钮文案可在题库 JSON 的 `features.practice.config` 里自定义（见 [JSON 规范](./EXAM_JSON_SPEC.md)）。

### 📝 摸底速览 —— 考前快速过一遍

按顺序铺开全部题目，每题两个按钮：

- **👀 查看答案** —— 单题展开/收起答案
- **➕ 加入错题本** —— 标记后进入错题本，来源记为「摸底速览」

适合考前 10 分钟扫一遍，或者刚导入新题库时先看看有什么。

### 🎯 分类考试 —— 正式自测

**开始前的设置页**：

- 选择题型（可多选，或点「全选」）
- 点 **🚀 开始考试**
- 也可以用「➕ 手动添加题目」临时加题，题目会进入本次考试

**答题中**：

- 填空题多空答案框下方有 **｜ 插入分隔符** 按钮，点一下就在光标处插入 `|`，不用手动打竖线
- 答对 **自动跳下一题**（约 0.6 秒延迟，方便扫一眼反馈）
- 答错 **停留在本题**，下方立即展示标准答案与解析，看明白再走；同时该题**实时**进入错题本（无需等考试结束）
- **← 上一题** 可回看已答的题，之前的作答状态会完整恢复（通过答题快照机制）
- 顶部显示已答对题数，右侧 **✕ 退出考试** 可随时中断——已答错的题也已留在错题本中，不因中途退出而丢失

**结束后**：

成绩页显示总题数、答对、答错、正确率、用时，以及错题列表。

### 📕 错题本 —— 集中攻克薄弱环节

错题本**全局去重**：同一道题无论在哪出错，只保留一条记录（来源会更新为最新一次出错场景）。

| 来源 | 产生方式 |
|---|---|
| 记忆闯关 | 点「没记住」，**实时**自动收录 |
| 摸底速览 | 点「➕ 加入错题本」 |
| 考试错题 | 分类考试里答错，**实时**自动收录（中途退出也不丢） |

每个 Tab 内可以：

- **查看** —— 展开答案与解析
- **加强练习** —— 对错题逐个自评；点 **😎 记住了** 即清除该题出本
- **重新考试** —— 组卷重考，**答对即移出错题本**
- **单条移除** / **清空**

> 移除规则：题只会在**错题本内部**被清除——练习中点「记住了」、重考答对，或手动移除/清空。在外面答对（比如闯关中又记住了、普通考试答对了）**不会**自动清掉错题本记录。

Tab 上的红色角标显示当前错题总数。

## 四、用 AI 生成题库

点右上角 **🤖 AI 提示词**（弹窗展示），点「📋 复制提示词」后配合题目截图或文本丢给任意大模型，它会按规范输出可直接导入的 JSON。

典型流程：

1. 拍下练习册 / 试卷的照片
2. 复制本项目的提示词 + 贴图片，发给 AI
3. 拿到 JSON 后在「📋 或粘贴 JSON 文本录入」里粘贴，点「应用」
4. 顺手点「📘 JSON 规则」下载规范，一并给 AI 效果更稳

## 五、数据存在哪

全部存在**浏览器 localStorage**，不上传任何服务器。

| Key | 内容 |
|---|---|
| `examBankCache:v2` | 题库缓存 |
| `examWrongbook:v1` | 错题本 |

因此：

- **换浏览器 / 换设备不同步** —— 用「⬇️ 下载 JSON」导出，另一台再导入
- **无痕模式关闭即丢** —— 别在无痕窗口里刷重要题库
- **清缓存会丢** —— 定期导出备份

## 六、常见问题

**Q：双击打开后是空白页？**
A：检查 `vendor/` 和 `js/` 目录是否和 `index.html` 在一起。它们必须保持相对路径结构。另外请勿用 IE —— 需要支持 ES2015+ 的现代浏览器（Chrome / Edge / Safari / Firefox 近几年的版本都行）。

**Q：我放了 `data.json` 为什么没加载？**
A：`file://` 协议下浏览器禁止 `fetch` 本地文件，属安全限制。用本地服务器打开即可（见 [部署指南](./DEPLOYMENT.md)），或直接拖拽文件导入。

**Q：导入后提示格式错误？**
A：确认 JSON 顶层有 `view: "exam-bank"` 和 `papers` 数组。不确定就点「📘 JSON 规则」对照，或参考 `history-example.json`。

**Q：题目里的选项没显示？**
A：单选/多选题需要 `options` 字段（`{ "A": "选项内容", ... }`），App 会自动拼到题干下方。

**Q：能多人共用一份题库吗？**
A：把 JSON 文件放静态服务器或对象存储上，用「🌐 远程链接」导入即可（记得开 CORS）。
